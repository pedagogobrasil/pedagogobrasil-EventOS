# EventOS Overview

EventOS is a professional platform for managing charity, community and institutional events.

The platform starts with a Bingo75 module, but the core is designed to support future modules such as raffles, auctions, tickets, donations and public accountability reports.

## Product Principles

- Security first.
- Clear and maintainable code.
- Modular architecture.
- Auditability.
- Accessibility.
- Documentation as part of the product.
